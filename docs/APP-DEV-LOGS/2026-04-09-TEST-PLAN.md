# OCLP Tahoe Test Plan - Post-Patch Verification
**Date:** 2026-04-09  
**Patches Applied:** 7d28f4d (Bug fixes + Root patches)  
**Target:** Macmini5,3 running macOS Tahoe 26.4  

---

## Overview

This test plan verifies the functionality of hardware components after applying root patches with the Bug 1 and Bug 2 fixes. The patches include:
- High Sierra GVA (video acceleration)
- Intel Sandy Bridge GPU (HD3000 graphics stack)
- Legacy USB 1.1 (OHCI/UHCI controller support)

---

## Pre-Reboot Checks (Run Now)

### 1. Patch Application Verification

```bash
# Verify patches were written to root volume
cat /System/Library/CoreServices/SystemVersion.plist | grep -E "ProductVersion|ProductBuildVersion"

# Check patch log exists
ls -la ~/Library/Logs/Dortania/ | head -5

# Verify kernel collections were rebuilt
ls -la /System/Library/KernelCollections/ | grep -E "Boot|System"
```

### 2. Snapshot Status

```bash
# List snapshots
diskutil apfs listSnapshots /

# Note the current XID - you'll need this for potential rollback
```

**Expected:** Multiple snapshots available, including the one created during patching.

### Test 2: Graphics & Desktop (Bug 1 Fix Verification)

**Objective:** Verify `os_data.tahoe` in `legacy_accel_support` enables Sandy Bridge graphics

| Step | Action | Expected Result | Status |
|------|--------|-----------------|--------|
| 2.1 | Desktop appearance | Color background appears (not gray) | ☐ |
| 2.2 | Wallpaper | Can change desktop wallpaper | ☐ |
| 2.3 | Transparency | Menu bar and Dock have transparency | ☐ |
| 2.4 | Animation | Mission Control animations work | ☐ |
| 2.5 | Open Photos app | Opens without crashing | ☐ |
| 2.6 | Play video in QuickTime | Video plays with GPU acceleration | ☐ |

**Commands:**
```bash
# Check loaded GPU kexts
kextstat | grep -i "Intel.*Graphics\|HD3000\|SNB"

# Check display info
system_profiler SPDisplaysDataType

# Check acceleration
system_profiler SPDisplaysDataType | grep -i "metal\|accelerat"
```

**Expected Output:**
- `AppleIntelHD3000Graphics.kext` loaded
- `AppleIntelHD3000GraphicsGLDriver.bundle` loaded
- Display shows Intel HD 3000 graphics

**Bug 1 Fixed:** If desktop has color and wallpaper works, the `legacy_accel_support` fix is working!
