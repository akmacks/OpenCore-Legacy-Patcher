## Recovery Procedure

### Step 1 — Confirm TDM disk (requires physical action)
```bash
# After reseating TB cable:
diskutil list
# Look for external disk ~500GB–1TB — that's the mini
```

### Step 2 — Mount mini volumes
```bash
sudo diskutil mount diskXsY   # EFI partition
sudo diskutil mount diskXsZ   # Server HD (APFS data)
```

### Step 3 — Roll back to last sealed snapshot
```bash
# Identify the mini's System volume container
MINI_VOL="/Volumes/Server HD"   # adjust if different
sudo mount -uw "$MINI_VOL"
sudo bless --mount "$MINI_VOL" --last-sealed-snapshot
```
> Note: `diskutil apfs revertSnapshot` does NOT exist on Tahoe.  
> `bless --last-sealed-snapshot` is the only supported rollback path.

### Step 4 — Ensure SSH survives reboot
```bash
# Check if RemoteLogin plist exists
ls /Volumes/[Preboot]/[UUID]/Library/Preferences/

# If missing, write it:
sudo defaults write /Volumes/[Server HD]/Library/Preferences/SystemConfiguration/com.apple.RemoteLogin RemoteLogin -bool true
```

### Step 5 — Unmount and reboot mini
```bash
sudo diskutil unmountDisk diskX   # mini's disk
# Then press-hold mini power or use its power button
```

### Step 6 — Restore tunnel from MBP
```bash
# On mini (once booted, if keyboard works):
tunnel-pro

# From MBP if mini has IP:
ssh akmacks@192.168.2.2   # via bridge
# or
ssh -p 2222 akmacks@localhost  # via tunnel
```

### Step 7 — Verify state
```bash
kextstat | grep -E "USB|Sandy|Intel|Airport|Bluetooth|HDA"
ifconfig bridge0 | awk '/inet /{print $2}'
tailscale ip -4
ping -c 3 8.8.8.8
```
