## Key Learnings

1. **USB 2.0 hub solves USB 1.1 device access** — wireless keyboard dongle through
   USB 2.0 hub works because the hub presents as USB 2.0 to the EHCI controller.
   Direct USB 1.1 port still needs OHCI/UHCI patches for old devices.

2. **Sandy Bridge GPU patches now stable** — previous freeze may have been caused
   by the AMFI conflict rather than the GPU patches themselves. With
   `amfi_get_out_of_my_way=0x7ff` resolving kext injection, the system is stable.

3. **sshd must be pre-enabled via LaunchDaemon** — on a headless machine with no
   USB HID, SSH is the only remote access path. Always enable before first boot.

4. **Setup Assistant runs after patch reboot** — macOS treats post-patch reboot
   as a software update completion and runs Setup Assistant. This is normal.
   Click through / Skip all optional features.
