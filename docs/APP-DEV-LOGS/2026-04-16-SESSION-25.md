**Controller Status:**
| Controller | Status | Instances |
|------------|--------|-----------|
| `AppleUSBEHCIPCI` | ✅ Active | 2 |
| `AppleUSBEHCIPort` | ✅ Active | 6 |
| `AppleUSBUHCIPCI` | ❌ Disabled | 0 |
| `AppleUSBUHCIPort` | ❌ Disabled | 0 |

**ACPI Layout:**
```
Bus 29: UHC1 (enabled) + UHC2-4 (disabled, _STA=9) + EH01 (active)
Bus 26: UHC5 (enabled) + UHC6-7 (disabled, _STA=9) + EH02 (active)
```

**Why "Other Bus" Appears:** System Information requires `usb-port-type` from `_UPC` methods. The renamed controllers (EH01/EH02) lack these descriptors, so macOS shows generic "Other Bus" (Location IDs: 0xfa000000, 0xfd000000).

**Why Mouse/Keyboard Work:** HID devices function via EHCI's **Transaction Translator (TT)** — a USB 2.0 fallback for USB 1.1 traffic. Functional but suboptimal (higher latency).
