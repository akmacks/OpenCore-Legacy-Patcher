✅ Bridge Restore is installed!

Version 1.0.2-alpha has been successfully installed on your Mac.

Getting started — open Bridge Restore:

open /Applications/BridgeRestore.app

Or use the terminal:

bridge-restore --gui # launch GUI dashboard bridge-restore --status # quick connection status bridge-restore --diag # full OSI L1–L7 diagnostics bridge-restore --help # all commands and flags man bridge-restore # read the full manual

First run

  • On first launch the Setup Wizard will guide you through configuration.
  • You will be asked to confirm your machine's role (Gateway or Client).
  • The Wizard writes ~/.config/bridge-restore/config.json.
