### New scripts committed (commit 8dc441e)

**scripts/install-on-mbp.sh** (225 lines)
MBP-side installer — mirrors install-on-mini.sh:
1. Writes /usr/local/bin wrappers: tunnel-mini, bridge-restore, tunnel-mini-status
2. Writes /etc/pf.anchors/bridge-restore with current uplink NAT rules
3. Hooks anchor into /etc/pf.conf (idempotent — checks before appending)
4. Writes local.nat-persist.plist to launchd/
5. Writes local.mbp-watchdog.plist to launchd/
6. Copies plists to ~/Library/LaunchAgents/ and loads both agents

**scripts/mbp-watchdog.sh** (120 lines)
Persistent MBP-side daemon (20s loop):
- Checks port 2222 open: `nc -z -G 2 localhost 2222`
- Checks ControlMaster alive: `ssh -O check macmini` equivalent
- If port open + CM dead: kills stale CM, runs tunnel-mini.sh
- State transitions: DOWN → UP → FAIL → DOWN
- macOS notifications on each state change
- Fail count threshold (5): suppresses notification spam
- Hardware UUID guard: refuses to run on non-MBP

**launchd/local.mbp-watchdog.plist**
- KeepAlive (restarts if exits non-zero)
- ThrottleInterval 10s (prevents rapid restart loops)
- Logs to ~/logs/mbp-watchdog.log

**launchd/local.nat-persist.plist**
- RunAtLoad only (exits when done — no KeepAlive needed)
- Sets ip_forwarding=1
- Waits up to 60s for bridge0 to exist
- Restores bridge0 = 192.168.2.1 if wrong
- Loads /etc/pf.anchors/bridge-restore via pfctl
- Logs to ~/logs/nat-persist.log
